# Фрибетчик — статус работы

Сайт-агрегатор фрибетов, бонусов и промокодов **только легальных букмекерских
контор** России. Дизайн адаптирован из присланного Figma-файла «Сайт Халявщик»
(купонный агрегатор) под тематику ставок.

## Стек
- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4 (тема в `app/globals.css`)
- Шрифт Inter (кириллица), брендовый акцент `#ff015c`

## Что уже сделано

### Разбор дизайна (не входит в репозиторий)
- Распарсен бинарный `.fig` (формат fig-kiwi + zstd) — извлечены все экраны,
  тексты, цвета и структура. Скрипты и рендеры лежат в `/home/ubuntu/figparse`
  и `/home/ubuntu/fig_extract` (вне репозитория).
- Определена палитра: `#ff015c` (акцент), `#222d39` (тёмно-синий),
  `#171717` (тёмный футер), `#f2f2f2` (фон), `#7838ff` (фиолетовый бейдж).
- Разобраны экраны: главная, шапка, футер, «по категориям», «по алфавиту»,
  блог + статья, о проекте, контакты, реклама на сайте, карточка бонуса.

### Каркас проекта
- `app/layout.tsx` — корневой layout (Header + Footer, метаданные, шрифт Inter).
- `app/globals.css` — тема Tailwind v4, брендовые цвета.
- `lib/data.ts` — **вся модель данных**: 12 букмекеров (Фонбет, Лига Ставок,
  Winline, БЕТСИТИ, PARI, Леон, Олимпбет, BetBoom, Марафон, Балтбет, Тенниси,
  Astrabet), 8 категорий бонусов, 13 бонусов/фрибетов, 4 статьи блога + хелперы.

### Готовые компоненты
- `components/Logo.tsx` — логотип «Фрибетчик».
- `components/BrandLogo.tsx` — сгенерированные лого-плитки БК (без чужих
  товарных знаков).
- `components/Stars.tsx` — рейтинг звёздами.
